## 💻 Local Setup & Development

To run the portfolio locally:

```bash
# Install dependencies
npm i

# Run local development server (Webpack Dev Server)
npm run dev
```

To build and serve production:

```bash
# Production build
npm run build

# Serve with Express server
npm start
```
